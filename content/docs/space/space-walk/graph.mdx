<Lead>
  **Graph** maps the workspace as projects, clusters, files, and connections. Use it to find an artifact, follow its neighborhood, or carry a group of related files into Timeline.
</Lead>

![Graph lens with projects and their mapped workspace files](/images/space/graph.png)

Open **Projects → Graph**, use `/space/#/graph`, or click **Map** on a [List](/docs/space/space-walk/files-explorer) row to focus that project.

## Move through the map

- **Click a node** to focus its immediate neighborhood and open the detail panel. The focus pill reports how many hops and nodes are included.
- **Double-click a cluster** to expand or collapse its files. Double-click a project to expand or collapse its clusters together.
- **Drag empty canvas** to pan, **drag a node** to reposition it, and use the **wheel** to zoom.
- **Hover a node** for its summary. Click a connection in the detail panel to follow it.
- Use **Clear**, the detail panel's close button, or **Esc** to clear focus. An open preview takes the first Esc.

The top-bar search is focused with **/**. Search by a mapped node's name or descriptive metadata, then select a result to focus it. Search navigates the map; the List and Tree have their own local filters.

## Read a file or follow time

Selecting a mapped file shows its name, path, date when available, description, and connections. **Preview file** opens the shared floating [preview window](/docs/space/space-walk/files-explorer#preview-a-file), including its Source toggle and Git version selector.

**Show on timeline** appears for files and clusters. It opens [Timeline](/docs/space/space-walk/timeline) with a focused trace of dated related files. Use **Clear trace** there to return to the wider timeline.

Dashboard uses project nodes and purpose environments; Graph uses the more detailed workspace map. Project todo satellites belong to [Dashboard](/docs/space/space-walk/dashboard), because Graph's file nodes represent a different level of detail.

## Change the graph root

Open the top-bar root picker, search for a node, and select it to reorganize the map around that node. Choose **Reset to …** in the same picker to return to the workspace center.

<Callout type="info">
  Re-rooting and dragging affect the visualization only. To change which directory Space treats as the workspace, use **XO root** in Setup.
</Callout>

## Coverage and reloads

Graph reads the derived map at `GET /xo/space.json`; it includes mapped files rather than every filesystem entry. An excluded or newly created file can still be browsable through the List drawer before it appears here.

Switching between Dashboard and Graph can reload the atlas to change datasets. An open preview is restored across that Projects lens change when browser session storage is available. Switching to another top-level tab closes the preview.
