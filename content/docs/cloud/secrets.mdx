<Lead>
  **Secrets** holds environment values for the agent in a space: API keys, tokens
  and connection strings. You paste them in once; afterwards the page shows their
  names, never their values.
</Lead>

## Add secrets

1. Open the space's **Secrets** page.
2. Under **ADD NEW**, paste the contents of a `.env` file: one `NAME=value` per
   line, for example `DATABASE_URL=postgres://...` and `API_KEY=sk-...`.
3. Choose **+ Save**.

The saved secrets are listed under **SECRETS** with their count. Each shows its
name and a masked value (••••••••).

![Secrets in a space's panel, highlighted: the ADD NEW box with Save, and three saved secrets, their values masked](/images/cloud/space-secrets-pane.png)

Model keys and data-source accounts have their own places in
[Setup](/docs/cloud/setup); use Secrets for anything else the agent needs.
