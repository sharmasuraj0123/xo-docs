<Lead>
  Most problems show up as one calm line above the message box, or as a short title on a message you sent. Find the words you see below, then follow what to do. Nothing you've typed is lost while Cowork waits for a problem to clear.
</Lead>

## Connection

### "Can't reach XO · retrying · what you see may be out of date"

**What it means:** Cowork can't reach XO Space right now. What's on screen may be a little behind.

**What to do:** check your internet connection. Cowork keeps retrying every few seconds and catches up on its own when XO is back. If you run Cowork yourself, see [If you run Cowork yourself](#if-you-run-cowork-yourself).

### "XO's chat engine isn't running · retrying · nothing you write is lost"

**What it means:** XO Space is up, but the part that runs your agents is starting or has stopped.

**What to do:** wait a few seconds. If the line stays, restart XO Space.

### "Connecting to XO…"

**What it means:** Cowork has just opened and is loading your workspace.

**What to do:** nothing. Sending is allowed as soon as it connects.

### "Signed out of the workspace. Reopen this app from XO."

**What it means:** your sign-in to the hosted workspace expired.

**What to do:** go back to XO and open Cowork again from there.

### The **Live** badge shows, but nothing happens

**What it means:** **Live** only says you're looking at your real workspace rather than the demo. It isn't a connection light.

**What to do:** look at the line above the message box. It tells you whether Cowork is connected.

## Your agent

### "Claude isn't connected · connect it in XO · sending waits until then"

**What it means:** Claude Code isn't signed in, so no agent can start.

**What to do:** sign Claude Code in from XO Space's setup, or by running `claude` in a terminal and logging in. Work that was waiting starts as soon as it's connected.

### "Paused until HH:MM · usage limit · running work finishes, new work waits"

**What it means:** your agent account reached its usage limit. Anything already running is allowed to finish. New work waits until the time shown.

**What to do:** wait for the reset, or sign Claude Code in to another account. Waiting work then starts on the new account right away.

### "Paused for your choice · your subscription moved onto paid usage · it's in Needs you"

**What it means:** your subscription has moved onto paid extra usage. Cowork won't spend that without asking you.

**What to do:** open **Needs you** and choose **Continue** (until your next limit reset) or **Wait**.

### "Couldn't run your message: it was tried 4 times and each try ended …"

**What it means:** the agent kept stopping partway through your message, so Cowork gave up after four tries. The reason follows in the message.

**What to do:** fix what the reason says (often the agent isn't signed in), then send your message again.

### "Couldn't start this session's CLI 5 times in a row"

**What it means:** Claude Code failed to start five times in a row.

**What to do:** check Claude Code works on its own: open a terminal and run `claude`. Then send any message in that thread or chat to try again.

## Sending messages

### "Sending is paused · …"

The message box tells you why it won't send:

| Reason | What to do |
| --- | --- |
| "XO's chat engine isn't running" | Wait, or restart XO Space. |
| "Can't reach XO right now" | Check your connection; Cowork retries on its own. |
| "Connecting to XO…" | Wait a moment. |
| "X isn't connected" | Sign the agent in. |
| "The router is off" | Turn routing back on in **Settings → Routing**. Replies inside a thread still work. |
| "This chat has ended" | Start a new chat from **Chats**. |

### A message shows an error title

Every message that didn't send has **Retry** and **Edit**. **Edit** puts your words (and any `@project`) back in the box.

| Title | What it means | What to do |
| --- | --- | --- |
| "The router is off" | New messages to the Workspace and projects are turned off. | Turn routing on in **Settings → Routing**, or reply inside a thread. |
| "This project was removed" | The project no longer exists in XO. Its conversation stays readable. | Create or add the project again. |
| "The agent isn't connected" | Claude Code isn't signed in. | Sign it in, then **Retry**. |
| "No agent can run this" | No agent that can do this work is set up. Today Cowork works with Claude Code. | Set up Claude Code. |
| "The coordinator is busy" | The coordinator was in the middle of a handover. | **Retry**. |
| "This thread is gone" | The thread no longer exists. | Write to the project to start new work. |
| "XO's chat engine isn't running" | XO Space is starting or stopped. | Wait, then **Retry**. |
| "No answer from XO" | XO didn't answer in time. | **Retry**. |
| "Not supported by this agent" | The agent can't do this yet. | Try it another way, or with another agent. |
| "Refused by the proxy" | The page you used isn't allowed to send this. | Reload Cowork from its own address. |
| "Can't reach XO" | Your connection or XO Space is down. | Check the connection, then **Retry**. |

### "This message reached no one: …"

**What it means:** your message was routed, but the coordinator it should go to couldn't start. The reason is in the message.

**What to do:** fix the reason (usually Claude Code isn't signed in), then send it again.

### "The coordinator couldn't answer: …"

**What it means:** the coordinator ran into a problem while replying.

**What to do:** read the reason, then send your message again.

### "Sending now stops N background task(s)…"

**What it means:** in a chat, **Send now** would stop work the chat started in the background.

**What to do:** choose **Add to the turn instead** to let that work carry on, or **Stop them and send**.

### "Couldn't stop it"

**What it means:** the stop didn't go through.

**What to do:** press **Retry** on that line.

## Decisions

### "Not sent: …"

**What it means:** your decision couldn't be delivered. The reason follows: it was already decided elsewhere, the agent withdrew the ask, or the ask expired.

**What to do:** nothing in most cases. If the agent still needs something, it will ask again.

### "A beat to read it first."

**What it means:** you pressed Allow very quickly on an ask worth reading.

**What to do:** read the card, then allow it.

### "Released early. Nothing was sent."

**What it means:** a destructive ask needs you to hold the button, and you let go too soon.

**What to do:** hold **Hold to allow** until it completes.

### A secret field says XO can't carry it

**What it means:** the agent asked for a secret, but it isn't waiting on that question any more, so Cowork won't keep your secret.

**What to do:** choose **Open the thread** and answer there when the agent asks again.

## Threads

### A thread won't start and explains why

Each thread in a git project works in its own copy of the project. If Cowork can't make one, the thread says why and waits for your next message:

| What the thread says | What to do |
| --- | --- |
| The project has no commit yet | Make one commit in the project, then send again. |
| The folder isn't a usable git repository | Fix the repository, then send again. |
| Something is already in the way of the thread's folder | Move that folder away, then send again. |
| The project's XO folder is a link | Make it a normal folder. |

A project that isn't a git repository at all still works. Its threads work directly in the project folder, and the thread says so.

### A thread paused itself

**What it means:** the agent kept trying something that wasn't allowed, so Cowork paused it rather than let it loop.

**What to do:** send the thread a message to get it going again, ideally with a different approach, or start a fresh thread.

### Working, but nothing seems to change

**What it means:** **Working** means the agent really is busy. Some steps take a while.

**What to do:** open the thread to see its current step and the checklist. To stop it, use **Stop** (it keeps what's done).

## Worktrees

These appear in **Settings → Worktrees** when you remove a thread's copy of the project.

| What you see | What it means | What to do |
| --- | --- | --- |
| "Has work not kept anywhere else" | Removing it would delete changes that exist nowhere else. | Keep it, or save the work first. To remove anyway, use **Hold to remove**: Cowork lists exactly what will be lost. |
| "Its agent is still using it" | The thread's agent is working in it. | Stop the thread, or try again once it has gone quiet. |
| "XO didn't make this checkout, so it won't remove it" | It was made by something other than Cowork. | Remove it yourself if you no longer need it. |
| "The checkout is already gone" | It was already deleted. | Nothing. |

## Files and sub-agents

| What you see | What it means |
| --- | --- |
| "This file is in a folder XO doesn't serve to the UI yet." | Cowork only opens files inside the thread's project. Use **Copy the path** to open it yourself. |
| "This file isn't there any more." | The file was moved or deleted after the agent shared it. |
| "Showing the first X of Y. The rest isn't previewed." | Large files are only partly shown. Open the file itself to see the rest. |
| "This agent can't show a sub-agent's work." | Your agent doesn't share what its helpers did. |
| "Its transcript is gone." | The record of that helper's work is no longer available. |
| "Messaging a sub-agent isn't possible; talk to its thread instead." | Write in the thread; its agent passes it on. |

## Creating a project

| What you see | What to do |
| --- | --- |
| "Give the project a name." | Type a name. |
| "Use at least one letter or number in the name." | Add a letter or number. |
| "There's already a project called “x”. Pick another name." | Choose a different name. |
| "Can't create yet: the projects folder is unknown. Is the XO API running?" | Make sure XO Space is running, then try again. |

## If you run Cowork yourself

If you host Cowork on your own machine and it can't connect, or the agent never starts:

1. **Make sure XO Space is running.** Start it again the way you installed it. Keep its terminal open: closing it stops XO Space.
2. **Make sure Cowork is running** and you opened it from its own address.
3. **Check Claude Code is installed and signed in.** Open a terminal, run `claude`, and sign in if asked.
4. **Run only one XO Space per workspace.** A second copy pointed at the same projects can't run your agents. Stop the extra one.
5. **Restart XO Space.** Most "isn't running" lines clear after a restart.
