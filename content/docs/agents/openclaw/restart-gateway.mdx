Two ways to restart your OpenClaw gateway: **OpenClaw Restart** in your space's app grid (fastest) or a terminal command (gives you logs).

<Tabs items={['App Grid', 'Terminal Command']}>
  <Tab value="App Grid">
    ## Restart from the App Grid

    1. Open [app.xo.builders](https://app.xo.builders) and choose your OpenClaw space under **My Spaces** in the sidebar. Its page opens.

    ![The sidebar's My Spaces with the beacon-desk space highlighted, its page open](/images/cloud/agent-openclaw-my-spaces.png)

    2. In the app grid on the right, choose **OpenClaw Restart**.
    3. Wait for the **OpenClaw gateway restarted** confirmation.

    ![The beacon-desk app grid with OpenClaw Restart highlighted, and the message OpenClaw gateway restarted](/images/cloud/agent-openclaw-restart.png)

    The gateway is now restarting. Wait a minute before opening **OpenClaw Gateway** again.
  </Tab>

  <Tab value="Terminal Command">
    ## Restart from Terminal

    1. On your OpenClaw space's page, choose **Web VS Code** in the app grid. VS Code opens on the space's files in a new browser tab (see [Browser VS Code](/docs/cloud/vs-code-server)).

    ![The beacon-desk app grid with Web VS Code highlighted](/images/cloud/agent-openclaw-web-vs-code.png)

    2. Open the terminal with **Ctrl + `** (backtick).
    3. Run the restart command:

    ```bash
    ./xo-cowork-api/openclaw.sh restart
    ```

    4. Check the command's output for any errors.
    5. For detailed logs, open `openclaw-gateway.log`.

    <Callout type="info">
      The terminal method is better for debugging: you can see errors in real time and check log files.
    </Callout>
  </Tab>
</Tabs>
