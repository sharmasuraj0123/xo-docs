This is the running weekly record of changes shipped across XO. The page footer shows the date this page was last built.

## November 25, 2026

### ☁️ XO Cloud setup guides rewritten

- The **Setup** guides now follow the current Setup page in a space's panel: [API keys](/docs/cloud/setup/models/api-key), [Connect Claude](/docs/cloud/setup/models/oauth/claude), [Connect Codex](/docs/cloud/setup/models/oauth/codex), [Google Drive](/docs/cloud/setup/data/google-drive), [OneDrive](/docs/cloud/setup/data/onedrive), [GitHub](/docs/cloud/setup/data/github) (token or device code), [Vercel](/docs/cloud/setup/data/vercel) (token or OAuth) and [channels](/docs/cloud/setup/channels), where the gateway restarts from **OpenClaw Restart** in the app grid.
- [Browser VS Code](/docs/cloud/vs-code-server) describes the current first launch: Restricted Mode, then **Manage** and **Trust**.
- Every XO Cloud screenshot retaken as a full screen, with the step's subject highlighted.

### 🤖 Agent guides refreshed

- The [OpenClaw](/docs/agents/openclaw/setup), [Hermes](/docs/agents/hermes/setup), [Claude Code](/docs/agents/claude-code/setup) and [Antigravity](/docs/agents/antigravity/setup) quickstarts follow one new space from **New Space** to its app grid, with new full-screen screenshots of every step in XO Cloud.
- The create forms are described as they are now: **OpenRouter** is a provider for OpenClaw and Hermes, the Hermes form offers Telegram and Slack, and **Volume Size** runs from 20 to 100 GB.
- Apps open from the space's app grid (**OpenClaw Gateway**, **Hermes Dashboard**, **Web VS Code**) and the gateways restart with **OpenClaw Restart** or **Hermes Restart**, in place of the old **Launch** tab.
- [Restart the Gateway](/docs/agents/openclaw/restart-gateway), [Switch to OpenAI Codex](/docs/agents/openclaw/models/switch-to-codex), [Add Venice AI](/docs/agents/openclaw/models/switch-to-venice), [Connect Slack](/docs/agents/openclaw/channels/connect-slack) and [Backup & Restore](/docs/agents/openclaw/skills/backup-restore) point to the app grid and the Setup page. Terminal and third-party screenshots were removed; each step is written out.

## November 24, 2026

### 📘 XO Space docs updated

- **Jobs** replaces Commands in Setup: create **Repeating** or **One time** jobs with schedules chosen in words, and run any job from **Inbox → Jobs** with **Run now**. See [Jobs](/docs/space/space-walk/commands).
- **Branding and themes**: name your workspace, add a logo, and pick one of five themes in **Setup → Workspace**. See [Setup](/docs/space/space-walk/setup#name-your-workspace-and-add-a-logo).
- **Account apps use your own Composio API key**, stored only on your machine; no XO sign-in is needed. See [Connectors](/docs/space/space-walk/connectors#add-your-composio-api-key).
- **Health checks** for the data Space keeps on your machine, in **Setup → Server → Technical details**.
- **Copy path** on every file and folder in the project file browser.
- One **Refresh** button in the top bar replaces the per-page refresh controls.
- Removing a project no longer depends on sharing, and **Clone project** in Sharing fills in the Add form for you.
- All XO Space screenshots retaken.

### 💬 Cowork docs, new

- A new **Cowork** section for the chat-first UI: [open Cowork](/docs/cowork/open-cowork), [decide what needs you](/docs/cowork/decide), [give work to a coordinator](/docs/cowork/coordinators), [follow a thread](/docs/cowork/threads), [review changes and files](/docs/cowork/changes-and-files), [find what agents made](/docs/cowork/artifacts-and-search), [use shells](/docs/cowork/shells) and [settings](/docs/cowork/settings). It replaces the old XO Cowork setup page.

### ☁️ XO Cloud docs rewritten

- Every XO Cloud page now matches the current app, with new screenshots: [create a space](/docs/cloud/create-a-space), [the dashboard](/docs/cloud/dashboard), [your space](/docs/cloud/your-space), [Work](/docs/cloud/work), [Setup](/docs/cloud/setup), [Secrets](/docs/cloud/secrets), [Apps](/docs/cloud/apps), [Usage](/docs/cloud/usage) and [Organizations](/docs/cloud/organizations).
- **Setup** (models, data sources, channels) moved under XO Cloud. Old links redirect.
- The agent guides use the current create flow: **New Space**, then **Create Space** on the agent's card.
