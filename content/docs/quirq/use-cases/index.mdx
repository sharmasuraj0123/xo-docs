The budgets come from the anchors in the
[playbook](/quirq/integrate/playbook): real prices, human baselines, market
comparables. The checks come from state the environment can capture. Per-check
pass rates then drive each family's economics: the weakest check dominates the
intervention rate, so improving one check moves the whole unit type.
