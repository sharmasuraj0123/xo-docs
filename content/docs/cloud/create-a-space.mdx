<Lead>
  A space is one agent on its own managed machine. You pick the agent, give the
  space a name, optionally add keys, and XO Cloud sets it up. When it is ready, the
  space opens and appears under **My Spaces**.
</Lead>

## What you need

- An [XO Cloud account](/docs/cloud/create-account).
- Optionally, a key for the agent's model provider. You can add it later in the
  space's [Setup](/docs/cloud/setup).

## Choose an agent

1. Choose **New Space** in the sidebar or on the dashboard. **Launch Your AI Team**
   opens on the **Agents** tab.
2. Each card is one agent, with **Overview** and **Details** tabs that say what it
   is good at and how much setup it needs. Pick one and choose **Create Space** on
   its card.

![Launch Your AI Team: agent cards for AI Executive Team, Codex, Antigravity, Hermes Agent, AI Research Team and XO Cowork](/images/cloud/create-space.png)

| Card | Agent | Notes on the card |
|---|---|---|
| **AI Executive Team** | OpenClaw | No coding required |
| **Codex** | OpenAI Codex | Featured |
| **Antigravity** | Google Antigravity | Featured |
| **Hermes Agent** | Hermes | |
| **AI Research Team** | Claude Code | Some technical setup needed |
| **XO Cowork** | OpenClaw | Experimental |

![The AI Research Team card: powered by Claude Code, its Overview and Create Space](/images/cloud/create-space-card.png)

To compare agents in more depth, see the [agent guides](/docs/agents).

The **Orgs** tab, **Launch Your AI Operations**, explains organizations: see
[Organizations](/docs/cloud/organizations).

## Fill in the form

The form depends on the agent. Every form has a **Space Name** and a **Volume Size
(GB)** (20 by default; use **−** and **+** to change it).

**Claude Code** (**Create New Claude Code Space**): add your **Anthropic API Key**
if you have one. It is optional; the eye icon shows or hides it.

![The Create New Claude Code Space form with a space name, the optional Anthropic API Key and Volume Size 20](/images/cloud/create-claude-code-form.png)

**XO Cowork** (**Create New XO Cowork Space**): you can fill in values now, or use
the interactive flow later to onboard.

- **AI Provider**: **Add Anthropic**, **Add OpenAI** or **Add OpenRouter**, then
  paste its **API Key**. **Remove** takes a provider out again.
- **Notification Channel**: **Add Telegram** (with its **Bot Token**), **Add
  WhatsApp** or **Add Slack**.

![The Create New XO Cowork Space form with Anthropic and Telegram added and their keys hidden](/images/cloud/create-xo-cowork-form.png)

For the other agents, see their guides: [OpenClaw](/docs/agents/openclaw/setup),
[Hermes](/docs/agents/hermes/setup) and [Antigravity](/docs/agents/antigravity/setup).

## Create the space

1. Choose **Create Space**.
2. XO Cloud shows **Workspace setup started**, then **Workspace setup completed**.
3. The new space opens. Its status reads **Ready**, and it is listed under **My
   Spaces** in the sidebar.

![The Create New Claude Code Space page in full, with the form filled in](/images/cloud/create-claude-code.png)
