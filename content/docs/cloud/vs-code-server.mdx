**Web VS Code** gives you a full VS Code editor in your browser, on the space's
files, with nothing to install. This guide covers the first launch, trusting the
folder, and opening a terminal.

## What You'll Need

- A space whose status reads **Ready** (see [Your space](/docs/cloud/your-space))

## Launch Web VS Code

1. On the space's page, choose **Web VS Code** in the app grid on the right. The
   editor opens in a new browser tab, on the space's home folder.

   ![A space's app grid with Web VS Code highlighted](/images/cloud/space-app-web-vs-code.png)

2. The first time, VS Code opens on its **Welcome** page in **Restricted Mode**: a
   banner at the top reads "Restricted Mode is intended for safe code browsing.
   Trust this folder to enable all features." Choose **Manage** in the banner.

3. **Workspace Trust** opens: "You are in Restricted Mode". Under **In a Trusted
   Folder**, choose **Trust**. The banner goes away and all features are enabled.

## Open a Terminal

You need a terminal to run space commands like `openclaw config`, `openclaw start`, and others.

<Steps>
  <Step>
    ### Keyboard Shortcut (Fastest)

    Press **Ctrl + `** (backtick) to toggle the integrated terminal panel.
  </Step>
</Steps>

**Alternatively**, use the menu:

<Steps>
  <Step>
    ### Open the Application Menu

    Click the hamburger menu icon (three horizontal lines) in the top-left corner.
  </Step>
  <Step>
    ### Select New Terminal

    Navigate to **Terminal** and click **New Terminal**.
  </Step>
  <Step>
    ### Start Typing Commands

    The terminal panel appears at the bottom. Click inside it and start running commands.
  </Step>
</Steps>

<Callout type="info">
  The terminal opens in your space's home directory by default. All your project files and configs live here.
</Callout>
