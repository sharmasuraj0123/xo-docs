<Lead>
  Connect your Claude subscription to a Claude Code or OpenClaw space. You sign in
  to Claude in a new browser tab and paste the code it gives you back into XO Cloud.
</Lead>

## What you need

- A space whose status reads **Ready** (see [Your space](/docs/cloud/your-space)).
- A Claude account with a subscription.

## Connect your Claude subscription

1. Open the space's **Setup** page and choose **Models**.
2. Under **OAUTH SUBSCRIPTIONS**, choose **Connect** on the **Claude** row.

   ![Setup › Models in a Claude Code space with the Claude row highlighted, showing its connected mark and Connect](/images/cloud/space-setup-models-pane.png)

3. The **Connect Claude subscription** dialog opens. Under **1 Sign in with Claude**,
   choose **Open sign-in page**. Claude's sign-in page opens in a new tab: sign in if
   asked, and approve access.

   ![The Connect Claude subscription dialog with Open sign-in page highlighted](/images/cloud/setup-claude-connect.png)

4. Claude shows a code. Copy it and switch back to the XO Cloud tab.
5. Under **2 Enter sign-in code**, paste the code and choose **Submit**.

   ![Step 2 of the dialog, Enter sign-in code, with a code pasted and Submit highlighted](/images/cloud/setup-claude-code.png)

When the subscription is connected, the **Claude** row shows a green check mark.
Close the dialog with **Close**.
