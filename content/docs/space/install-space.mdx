## Install a local Space

Run this command in a terminal:

```bash
curl -fsSL quirq.ai/install | sh
```

The installer downloads or updates Space, reports available optional tools, and
starts your local Space at [http://localhost:5002/space/](http://localhost:5002/space/).
Keep the terminal running while you use Space; press `Ctrl-C` to stop it.

<Callout type="info">
	The installer endpoint and its technical state directory retain the Quirq
	name. Logs are stored at `~/.quirq/quirq.log`, but the installed and running
	environment is a **Space**. See [Glossary](/docs/glossary).
</Callout>

## Optional tools

The installer reports optional integrations individually. Node and npm enable
the agent CLI at boot, while GitHub CLI (`gh`) enables repository backup. If an
optional tool is missing, only the adjacent feature is unavailable.

## Local or cloud

A **Space** is the environment where the agent works in either place. This page
installs that environment **on your machine**. To run on an XO-provisioned
remote machine instead, use [XO Cloud](/docs/cloud/overview).
