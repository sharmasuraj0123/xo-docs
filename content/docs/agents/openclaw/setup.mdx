OpenClaw is an AI agent gateway you deploy on XO. Create a space with a model provider and a messaging channel, and your agent is live, with no infrastructure to manage.

## Setup Walkthrough

<VideoEmbed id="f1b132df7f084b6084b794e2b3ce6a96" title="OpenClaw Setup on XO Builders" />

## What You'll Need

- An [XO account](https://app.xo.builders)
- **At least one model provider:** an Anthropic, OpenAI or OpenRouter API key
- **At least one channel:** a Telegram bot token (from [@BotFather](https://t.me/botfather)), a WhatsApp QR scan, or a Slack bot token and app token

Any combination of providers and channels works.

## Deploy OpenClaw

<Steps>
  <Step>
    ### Choose AI Executive Team
    Go to [app.xo.builders](https://app.xo.builders/) and choose **New Space** in the sidebar.
    On the **AI Executive Team** card (Powered by OpenClaw), choose **Create Space**. See
    [Create a space](/docs/cloud/create-a-space) for the whole flow.

    ![New Space with the AI Executive Team card highlighted: Powered by OpenClaw, with Create Space](/images/cloud/agent-openclaw-card.png)
  </Step>
  <Step>
    ### Fill In the Space
    The form, **Create New Open Claw Space**, starts with **Anthropic** under **AI Provider** and **Telegram** under **Notification Channel**:

    | Field | Value |
    |---|---|
    | **Space Name** | A unique name, e.g. `beacon-desk`. Note it down: it is your Gateway Token later. Up to 32 letters, numbers and hyphens, starting with a letter or number. |
    | **AI Provider** | **Anthropic** › **API Key**. **Add OpenAI** and **Add OpenRouter** add those providers, each with its own **API Key**. |
    | **Notification Channel** | **Telegram** › **Bot Token**. **Add WhatsApp** shows a QR code to scan with WhatsApp; **Add Slack** asks for a **Bot Token** and an **App Token**. |
    | **Volume Size (GB)** | The space's disk, from 20 (the default) to 100. |

    **Remove** takes a provider or channel off the form. At least one provider and one channel are required, and each one you add needs its key or token.

    ![The Create New Open Claw Space form highlighted: Space Name beacon-desk, an Anthropic API Key and a Telegram Bot Token filled in, Add OpenAI, Add OpenRouter, Add WhatsApp, Add Slack, Volume Size 20](/images/cloud/agent-openclaw-form.png)

    Choose **Create Space**.
  </Step>
  <Step>
    ### Wait for Startup
    XO Cloud opens the new space's page. The space is ready when its card reads **Ready** and **Status & Metadata** shows **XO SPACE API** **Up**. **Machine Logs** lists what the machine did as it started.

    ![The beacon-desk space's page with its card highlighted: openclaw, Stops in 29d, Ready and Stop](/images/cloud/agent-openclaw-ready.png)
  </Step>
  <Step>
    ### Check the Setup
    Open the space's **Setup** page: the blue round icon in the dock at the bottom of the panel on the right (see [Your space](/docs/cloud/your-space#the-spaces-pages)).

    In **Setup › Models**, the provider you added reads **Connected**.

    ![Setup › Models in beacon-desk with the Anthropic row highlighted: Connected](/images/cloud/agent-openclaw-models.png)

    In **Setup › Channels**, the channel you added reads **Connected**.

    ![Setup › Channels in beacon-desk with the Telegram row highlighted: Connected](/images/cloud/agent-openclaw-channels.png)

    You can add or change providers, data sources and channels on these pages later. See [Setup](/docs/cloud/setup).
  </Step>
  <Step>
    ### Connect Codex (Optional)
    To use Codex through your ChatGPT subscription instead of an API key, choose **Connect** on the **OpenAI** row under **OAUTH SUBSCRIPTIONS** in **Setup › Models**. See [Connect Codex](/docs/cloud/setup/models/oauth/codex) for the whole flow.
  </Step>
  <Step>
    ### Open the OpenClaw Gateway
    Go back to the space's page (choose the space under **My Spaces** in the sidebar). In the app grid, choose **OpenClaw Gateway**. The OpenClaw dashboard opens in a new browser tab.

    ![The beacon-desk app grid with OpenClaw Gateway highlighted](/images/cloud/agent-openclaw-gateway.png)
  </Step>
  <Step>
    ### Connect to the Gateway
    In the OpenClaw dashboard's **Gateway Token** field, enter your space name exactly as you typed it in step 2 (e.g. `beacon-desk`), then choose **Connect**. The status indicator turns **green (OK)** when connected.
  </Step>
  <Step>
    ### Test Your Agent
    Go to the **Chat** tab in the OpenClaw dashboard's sidebar and send a message, for example `hello`. Your agent answers: OpenClaw is live. You can also message it on the channel you connected.
  </Step>
</Steps>

<Callout type="warn">
  The Gateway Token must exactly match your space name from step 2. A mismatch will prevent the dashboard from connecting.
</Callout>
