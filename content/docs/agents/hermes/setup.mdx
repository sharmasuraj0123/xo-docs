Set up a Hermes agent on XO: name your space, add your model and channel credentials, and open the Hermes dashboard to monitor your agent.

## Setup Walkthrough

<VideoEmbed id="6d54e38381054f54bd1bf589a831ad38" title="Hermes Setup on XO Builders" />

## What You'll Need

- An [XO account](https://app.xo.builders)
- *(Recommended)* a **model provider:** an Anthropic, OpenAI or OpenRouter API key
- *(Recommended)* a **channel:** a Telegram bot token (from [@BotFather](https://t.me/botfather)), or a Slack bot token and app token

Both are optional when you create the space: you can add them later on the space's **Setup** page. Adding at least one of each up front is recommended.

## Deploy Hermes

<Steps>
  <Step>
    ### Choose Hermes Agent
    Go to [app.xo.builders](https://app.xo.builders/) and choose **New Space** in the sidebar.
    On the **Hermes Agent** card (Powered by Hermes), choose **Create Space**. See
    [Create a space](/docs/cloud/create-a-space) for the whole flow.

    ![New Space with the Hermes Agent card highlighted: Powered by Hermes, with Create Space](/images/cloud/agent-hermes-card.png)
  </Step>
  <Step>
    ### Fill In the Space
    Fill in **Create New Hermes Agent Space**:

    | Field | Value |
    |---|---|
    | **Space Name** | A unique name, e.g. `relay-hermes`. Note it down: you sign in to the Hermes dashboard with it. Up to 32 letters, numbers and hyphens, starting with a letter or number. |
    | **AI Provider** | **Add Anthropic**, **Add OpenAI** or **Add OpenRouter**, then paste that provider's **API Key**. |
    | **Notification Channel** | **Add Telegram** (a **Bot Token**) or **Add Slack** (a **Bot Token** and an **App Token**). |
    | **Volume Size (GB)** | The space's disk, from 20 (the default) to 100. |

    The form starts with no provider or channel. Each one you add needs its key or token; **Remove** takes it off the form again.

    ![The Create New Hermes Agent Space form highlighted: Space Name relay-hermes, Anthropic and Telegram added with an API Key and a Bot Token filled in, Add OpenAI, Add OpenRouter, Add Slack, Volume Size 20](/images/cloud/agent-hermes-form.png)

    Choose **Create Space**.
  </Step>
  <Step>
    ### Wait for Startup
    XO Cloud opens the new space's page. The space is ready when its card reads **Ready** and **Status & Metadata** shows **XO SPACE API** **Up**.

    ![The relay-hermes space's page with its card highlighted: hermes, Stops in 29d, Ready and Stop](/images/cloud/agent-hermes-ready.png)
  </Step>
  <Step>
    ### Check the Setup
    Open the space's **Setup** page: the blue round icon in the dock at the bottom of the panel on the right (see [Your space](/docs/cloud/your-space#the-spaces-pages)). **Setup › Overview** has three cards, **Models**, **Data** and **Channels**, each with **Open**.

    ![Setup › Overview in relay-hermes, highlighted: the Models, Data and Channels cards, each with Open](/images/cloud/agent-hermes-setup.png)

    Open **Models**: the provider you added reads **Connected**. If you skipped it, add a key under **API KEYS** (see [Add an API key](/docs/cloud/setup/models/api-key)) or connect a subscription under **OAUTH SUBSCRIPTIONS**.

    ![Setup › Models in relay-hermes with the Anthropic row highlighted: Connected](/images/cloud/agent-hermes-models.png)

    **Channels** works the same way: the channel you added reads **Connected**, and you can add Telegram or Slack there later. See [Setup](/docs/cloud/setup).
  </Step>
  <Step>
    ### Open the Hermes Dashboard
    Go back to the space's page (choose the space under **My Spaces** in the sidebar). In the app grid, choose **Hermes Dashboard**. The dashboard opens in a new browser tab.

    ![The relay-hermes app grid with Hermes Dashboard highlighted, next to Hermes Restart](/images/cloud/agent-hermes-dashboard.png)

    You'll land on the dashboard's sign-in page. Sign in with your **space name** as both the username and the password. The Hermes Agent dashboard opens.

    Your agent is now live. Send it a message from your connected messaging app (Telegram or Slack), and monitor active conversations from the dashboard.
  </Step>
</Steps>

## Restart Hermes

To restart the Hermes gateway, for example when your agent stops answering, choose **Hermes Restart** in the space's app grid. XO Cloud confirms with **Hermes gateway restarted**.

![The relay-hermes app grid with Hermes Restart highlighted, and the message Hermes gateway restarted](/images/cloud/agent-hermes-restart.png)
