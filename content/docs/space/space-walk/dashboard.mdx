<Lead>
  The **Dashboard** organizes your workspace projects into purposeful visual clusters. It collapses each project into an interactive node, with active agent tasks tethered directly to the project they belong to.
</Lead>

## Purpose Environments

Instead of a flat list of folders, the Dashboard groups projects by **Environment** (e.g. Research, Core Infrastructure, Production Apps, Alter-Ego Agents).

- **Environment Clusters**: Visually delineate related codebases.
- **Project Nodes**: Each project is represented as a distinct node with status badges and health indicators.

## Orbiting Todos

When you select a project node on the Dashboard:

- **In-Progress Work**: Open tasks and active agent objectives orbit the node like satellites.
- **Tethered Connections**: Lines connect active todos to the files and components they touch.
- **Detail Panel**: The right sidebar displays the complete checklist, task descriptions, and recent execution history.
