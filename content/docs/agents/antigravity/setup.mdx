Set up a Google Antigravity agent on XO: create a space, open the browser-based editor, and run `antigravity` to start a session.

## What You'll Need

- An [XO account](https://app.xo.builders)
- A Google account to sign in to Antigravity when you first launch it

## Deploy Antigravity

<Steps>
  <Step>
    ### Choose Antigravity
    Go to [app.xo.builders](https://app.xo.builders/) and choose **New Space** in the sidebar.
    On the **Antigravity** card (Powered by Google), choose **Create Space**. See
    [Create a space](/docs/cloud/create-a-space) for the whole flow.

    ![New Space with the Antigravity card highlighted: Powered by Google, with Create Space](/images/cloud/agent-antigravity-card.png)
  </Step>
  <Step>
    ### Fill In the Space

    **Create New Antigravity Space** asks only for a unique **Space Name**, for example `orbit-gravity`, and the **Volume Size (GB)**, the space's disk, from 20 (the default) to 100. Choose **Create Space**.

    ![The Create New Antigravity Space form highlighted: Space Name orbit-gravity, Volume Size 20, Cancel and Create Space](/images/cloud/agent-antigravity-form.png)
  </Step>
  <Step>
    ### Wait for Startup

    XO Cloud opens the new space's page. Wait until its card reads **Ready** and **Status & Metadata** shows **XO SPACE API** **Up**.

    ![The orbit-gravity space's page with its card highlighted: antigravity, Stops in 29d, Ready and Stop](/images/cloud/agent-antigravity-ready.png)

    <Callout type="info">
      Don't go on until the space is ready.
    </Callout>
  </Step>
  <Step>
    ### Open Your Editor

    In the app grid on the right, choose **Web VS Code**: VS Code opens on the space's files in a new browser tab. The first time, it opens in **Restricted Mode**: choose **Manage** in its banner, then **Trust**.

    ![The orbit-gravity app grid with Web VS Code highlighted; Antigravity IDE is next to it](/images/cloud/agent-antigravity-apps.png)

    Full walkthrough: [Browser VS Code](/docs/cloud/vs-code-server).
  </Step>
  <Step>
    ### Start a Session

    Open a terminal with **Ctrl + `** and run:

    ```bash
    antigravity
    ```

    On first launch, sign in with your Google account. Your Antigravity agent is now ready to work on the project.
  </Step>
</Steps>

Your Antigravity agent is now running inside your XO space.
