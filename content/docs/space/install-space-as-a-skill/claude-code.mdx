## Install the Space skill

In Claude Code, run these commands in order:

<Steps>
	<Step>
		### Add the Quirq marketplace

		```text
		/plugin marketplace add quirq-ai/xo-space
		```

		This registers the marketplace that provides the Space skill.
	</Step>
	<Step>
		### Install the plugin

		```text
		/plugin install quirq@quirq-ai
		```

		`quirq` is the plugin's published identifier. It installs Space's CLI
		integration into Claude Code.
	</Step>
	<Step>
		### Reload plugins

		```text
		/reload-plugins
		```

		Reload Claude Code so the installed skill is available in the current
		session.
	</Step>
</Steps>

## Start with a Space

Ask Claude Code: **“Help me set up a Space for this task.”** The skill supplies Space context and starts a guided interaction. Follow the product guidance it provides rather than relying on undocumented slash commands.

To install and run a Space directly, see [Install Space](/docs/space/install-space),
then [Your first Space](/docs/space/first-space).
