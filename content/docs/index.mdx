## Quick Answers

<Accordions>
	<Accordion title="Is XO free?">
		Hosted XO on [app.xo.builders](https://app.xo.builders) is not free. Every
		new account gets a **30-day Basic trial** when you sign up so you can try
		the product. After the trial, you need a paid plan. You always bring your
		own model (API key or OAuth).

		Want to try without a cloud subscription? [Install Space
		locally](/docs/space) and run it on your machine.
	</Accordion>
	<Accordion title="Do I need my own model key?">
		You bring your own model: use an API key from Anthropic, OpenAI, or
		OpenRouter, or connect via OAuth with your existing Claude or ChatGPT
		subscription. XO does not sell model credits.
	</Accordion>
	<Accordion title="What can I actually run?">
		Five agent templates (OpenClaw, Claude Code, Hermes, XO Cowork,
		Antigravity), XO Launchpad deploys, and purpose-built environments for
		real work and experimentation.
	</Accordion>
	<Accordion title="What is the difference between XO Space and XO Cloud?">
		A **Space** is where the agent works. **XO Space** runs that environment
		on your machine. **XO Cloud** runs it on an isolated remote machine you
		manage from the dashboard. See [XO Space](/docs/space) and
		[XO Cloud](/docs/cloud), or the [Glossary](/docs/glossary).
	</Accordion>
	<Accordion title="Do I need to install anything?">
		**XO Cloud:** no local install—everything runs in a hosted space and
		browser IDE. **XO Space:** yes—run the local installer (or an agent
		skill), then open the Space UI on localhost.
	</Accordion>
	<Accordion title="Is My Data Secure?">
		On **XO Cloud**, credentials live in your space and each project gets
		an isolated machine. On **XO Space**, work stays on your machine under
		your control. See the [Glossary](/docs/glossary) for how those layers are
		named.
	</Accordion>
</Accordions>
