<Lead>
  **XO Space** is a Space running on **your machine**. It is the environment where
  your agent works and where work gets done—without provisioning a remote XO
  workspace.
</Lead>

## XO Space vs XO Cloud

| | **XO Space** (this path) | **XO Cloud** |
|---|---|---|
| Where the agent runs | **Your machine** (local Space UI) | Isolated **workspace machine** on XO |
| How you start | Install script or agent skill | Sign up → New Project → template |
| XO account | Not required to install and run | Required |
| URL / entry | Typically `http://localhost:5002/space/` | [app.xo.builders](https://app.xo.builders) |
| Same idea | A **Space** is where the agent works | Same |

Need a managed remote machine, sharing, and dashboard ops? Use the
[XO Cloud](/docs/cloud) track.

Platform words are defined once in the [Glossary](/docs/glossary).

<Callout type="info">
  **Space** is the product concept. Older install URLs and log directories may still
  say Quirq (`quirq.ai/install`, `~/.quirq/`). Those paths install and run
  **Space**.
</Callout>
