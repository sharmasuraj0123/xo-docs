## How Cowork is organised

| Area | Where | What it is for |
|---|---|---|
| **Home** | First item in the sidebar | What is worth your time across every project, ranked, with **Your next move** on top. |
| **Needs you** | Opens beside Home when you choose **Decide** | One decision at a time: a permission, a question or an approval. |
| **Workspace** | Sidebar | Your coordinator across all projects. Tell it what should get done; it routes the work. |
| **Projects** | Sidebar, under **Projects** | Each project's own coordinator conversation, its threads in progress and every thread it has had. |
| **Threads** | Opened from a project | One agent working on one task, with its checklist, its branch and the files it changed. |
| **Artifacts** | Sidebar | Everything your threads made: documents, pictures and branches. |
| **Shells** | Sidebar foot | Terminals in a project folder or a thread's worktree, kept in a dock. |
| **Settings** | Sidebar foot | Shape, routing, runtimes, rules and the rest. |

The sidebar also lists **Chats**: a chat is one agent in one folder, outside your
projects' coordinators. Press **Ctrl K** (**⌘K** on macOS) anywhere to jump to a
place, a project, a thread or a file a thread made.

The sidebar shows your workspace's name (**Space** by default) and a theme switch.
Cowork opens in its dark theme.

## Words Cowork uses

| Word | Meaning |
|---|---|
| **Coordinator** | The agent you talk to in the Workspace or in a project. It answers, forwards your message or starts a thread. |
| **Thread** | One task given to one agent. It runs on one runtime for its whole life and works in its own checkout of the project (a worktree) on its own branch. |
| **Checklist** | The steps a thread's agent plans, with the current step marked. |
| **Ask** | Something a thread or coordinator needs from you: a decision, an answer or an approval. |
| **Runtime** | The agent program a thread runs on, for example Claude Code or Codex. |
