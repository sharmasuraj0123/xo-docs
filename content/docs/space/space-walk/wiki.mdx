<Lead>
  **Wiki** is a compact starting point for learning Space. Select **Wiki** at the
  top right, beside **GitHub**, or use `/space/#/wiki`. It opens a local quick
  start and topic directory in the same browser tab, with links to the full
  guides.
</Lead>

![The compact Wiki directory with a quick start and links to detailed Space guides](/images/space/wiki.png)

## Find a guide

Scroll the single page to find the topic you need. Each topic explains when to
use that part of Space. **Open docs** opens its detailed guide on
[docs.quirq.ai](https://docs.quirq.ai/docs/space) in a new browser tab, keeping your
workspace view available.

| Topic | Continue with |
| --- | --- |
| Projects | [Workspace views and project lenses](/docs/space/space-walk) |
| Timeline | [Git history and timeline playback](/docs/space/space-walk/timeline) |
| Sessions | [Usage, tools and recorded prompts](/docs/space/space-walk/sessions) |
| Inbox | [Incoming work and attention items](/docs/space/space-walk/inbox) |

| Connectors | [Accounts, agent actions and polling](/docs/space/space-walk/connectors) |
| Contribute | [Development setup and contribution workflow](/docs/space/contributing) |

Where a topic has **Open view**, that action takes you to the corresponding live
view inside Space. The quick start also helps you move from checking Setup to
browsing projects and following work.

The top-right **Wiki** link opens this directory from any view. Wiki is separate
from the six primary tabs and has no numbered shortcut. **GitHub** beside it
opens the Space source repository in a new tab.

## Match guidance to the running app

The compact directory and its short summaries ship with the Space application.
Detailed guides live on the documentation website and can be updated separately.
Check the version notes in a guide when its controls or examples differ from
your installed build. Older Space versions may still show a longer bundled
manual instead of this directory.

The local Wiki overview remains available when Space is reachable without
internet access; opening a full guide requires access to the documentation
website. External documentation is not bundled for offline reading.

Use [Setup](/docs/space/space-walk/setup) for the roots and runtime configured on
your machine, and the relevant live view for its current data and freshness
timestamps. Paths shown in documentation are examples, not a reading of your
installation's configuration.
