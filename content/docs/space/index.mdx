## Not the Cloud path

| | **XO Space** (this section) | **XO Cloud** |
|---|---|---|
| Where it runs | Your laptop | Hosted workspace machine |
| How you start | Install / skill | Account → New Project |
| Dashboard Setup tab | No | Yes — under [Workspace configuration](/docs/setup) |
| Agent quickstarts in docs | Local walkthrough | [AI Agent Guides](/docs/agents) (Cloud) |

Need hosted machines, sharing, and the dashboard? Use **[XO Cloud](/docs/cloud)** — that section also contains Workspace Configuration and AI Agent Guides.

	Older install URLs may still say Quirq (`quirq.ai/install`, `~/.quirq/`).

</Callout>
