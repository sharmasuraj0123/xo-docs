## Quick Answers

<Accordions>
	<Accordion title="Is XO Space free?">
		Yes! **XO Space** is open-source. You can run Space locally on your machine for free with a single `curl` command to observe and measure your local agents.
		
		If you prefer a managed environment, **XO Cloud** on [app.xo.builders](https://app.xo.builders) provides pre-provisioned cloud infrastructure (includes a 30-day trial). You bring your own model key in both cases.
	</Accordion>
	<Accordion title="Do I need my own model key?">
		You bring your own model: use an API key from Anthropic, OpenAI, or
		OpenRouter, or connect via OAuth with your existing Claude or ChatGPT
		subscription. XO does not sell model credits.
	</Accordion>
	<Accordion title="What is the relationship between XO Space and XO Cloud?">
		**XO Space** is the core open-source engine (`cowork-api`) for agent execution and observability. **XO Cloud** is simply a managed way to launch Space on remote infrastructure. Anything you can do on XO Cloud can also be done locally with XO Space.
	</Accordion>
	<Accordion title="How do I observe local agents?">
		Install Space locally using `curl -fsSL quirq.ai/install | sh` (or add it as an agent skill). Launch the local UI on `localhost:5002` to watch live agent sessions, inspect tool execution, and track performance metrics.
	</Accordion>
	<Accordion title="Is my data secure?">
		On **Local Space**, work and telemetry stay 100% on your machine. On **Cloud Space**, credentials live in isolated cloud containers under your control. See the [Glossary](/docs/glossary) for details.
	</Accordion>
</Accordions>
