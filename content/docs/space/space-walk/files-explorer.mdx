<Lead>
  The **Files** tab in XO Space gives you three distinct lenses over your workspace projects. The **List** lens gives every project a dedicated row with rich metadata, while the **Project Drawer** and **Viewer** let you inspect files without losing context.
</Lead>

![XO Space Files List View](/images/space/files-list.png)

## The List View

In the List lens, every project in your `XO_PROJECTS_ROOT` appears as an interactive card:

- **Project Description**: Extracted automatically from the project's local `README.md` or `PROJECT.md`.
- **File & Folder Metrics**: Live file counts and folder depth.
- **Active Agent Status**: A live pulse indicating whether an agent (Claude Code, OpenClaw, Hermes, Antigravity, etc.) is currently executing tasks inside that directory.
- **Last Activity Timestamp**: Sourced from the in-memory file watcher.

---

## The Project Drawer & In-Place File Viewer

Clicking on any project row slides open the two-pane **Project Drawer** and file viewer:

![XO Space In-Place File Viewer](/images/space/files-viewer.png)

1. **Left Pane (File Tree)**: Browse the project's subdirectories and files in an interactive explorer.
2. **Right Pane (Context & Events)**:
   - **Active Todos**: Open tasks and checkboxes pulled from `PLAN.md` / `todos.json`.
   - **Open Sessions**: Active and recent chat session threads.
   - **Watcher Events**: Real-time stream of file additions, modifications, and deletions.

### Safe In-Place Previews

Clicking any file opens the preview drawer without navigating you away from your current work:

- **Markdown**: Rendered with GitHub-flavored markdown, headings, code blocks, and math.
- **HTML**: Sandboxed in an isolated `iframe` with `sandbox="allow-scripts"` disabled and zero same-origin access.
- **Code & Text**: Displayed with escaped syntax highlighting and line numbers.
