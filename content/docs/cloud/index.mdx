This section is the **XO Cloud** path: account, templates, remote workspace
machine, day-to-day controls, **Workspace Configuration** (Setup tab), and
**AI Agent Guides** (per-template Cloud quickstarts).

For a Space on your machine, see [XO Space](/docs/space) — that track does not
use the Cloud dashboard Setup tab or these agent deploy guides.
