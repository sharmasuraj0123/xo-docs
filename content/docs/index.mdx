## Quick Answers

<Accordions>
	<Accordion title="Is XO free?">
		Yes. The Basic plan is free, and sign-up takes under 2 minutes. You bring
		your own model (API key or OAuth), so you only pay for the AI usage you
		already have.
	</Accordion>
	<Accordion title="Do I need my own model key?">
		You bring your own model: use an API key from Anthropic, OpenAI, or
		OpenRouter, or connect via OAuth with your existing Claude or ChatGPT
		subscription. XO does not sell model credits.
	</Accordion>
	<Accordion title="What can I actually run?">
		Five agent templates (OpenClaw, Claude Code, Hermes, XO Cowork,
		Antigravity), XO Launchpad deploys, and purpose-built environments for
		real work and experimentation.
	</Accordion>
	<Accordion title="Do I need to install anything?">
		No. Everything runs in the cloud browser IDE — secure, isolated
		spaces with no local setup or infra to manage.
	</Accordion>
	<Accordion title="Is my data secure?">
		Credentials live in your space. Each project gets an isolated
		machine so agents and secrets stay separated from other users.
	</Accordion>
</Accordions>
