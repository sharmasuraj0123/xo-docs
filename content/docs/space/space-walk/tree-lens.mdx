<Lead>
  The **Tree Lens** provides a panoramic, horizontal visual hierarchy of your workspace. It maps directory depth from left to right, allowing you to instantly assess the shape, complexity, and distribution of files across all your projects.
</Lead>

## How the Tree Works

- **Horizontal Columns**: The workspace root sits on the far left. Each column to the right represents an additional level of directory depth.
- **Dynamic Branch Thickness**: Branch line thickness scales proportionally with the number of files and directories contained within that limb.
- **Leaf Cards**: Files and leaf nodes are stacked cleanly beside the directory branch that contains them.

## Interactive Navigation

1. **Pan & Zoom**: Smoothly navigate large multi-project workspaces with trackpad or mouse gestures.
2. **Instant Preview**: Clicking any file node in the Tree immediately renders the in-place preview drawer.
3. **Filtering**: Search by filename or file extension to spotlight relevant branches while fading out unrelated directories.
