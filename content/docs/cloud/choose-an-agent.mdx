The documented agent templates share the same XO space foundation, but they are designed for different ways of working.

## Choose by What You Want to Do

- **Work primarily from messaging apps and add skills or integrations:** choose [OpenClaw](/docs/agents/openclaw).
- **Develop software from a browser-based editor and terminal:** choose [Claude Code](/docs/agents/claude-code).
- **Run a messaging-first assistant with its own monitoring dashboard:** choose [Hermes](/docs/agents/hermes).
- **Develop with Google's agent-first coding platform:** choose [Antigravity](/docs/agents/antigravity).

## Before You Decide

| Agent | Main experience | Credentials to prepare |
|---|---|---|
| **OpenClaw** | OpenClaw dashboard plus connected messaging channels | At least one supported model provider and one channel |
| **Claude Code** | Browser IDE and the `claude` terminal interface | An Anthropic API key or a Claude account for OAuth |
| **Hermes** | Hermes dashboard plus a connected messaging channel | A model provider and channel are recommended; they can also be added later |
| **Antigravity** | Browser IDE and the `antigravity` terminal interface | A Google account for sign-in on first launch |

For a fuller feature comparison and links to every agent guide, see [Agents](/docs/agents).

## Next Step

Once you have chosen an agent, [create your XO account](/docs/cloud/launch-first-agent) if needed, then [launch your first agent](/docs/cloud/launch-first-agent).
