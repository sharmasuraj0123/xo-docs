<Lead>quirq accounting needs no new infrastructure: an environment that snapshots state and meters spend, and four habits. Start with one recurring task family this week.</Lead>

## Start with a Space

Install a Space directly from a terminal, or add it to Claude Code, then begin
with a task you already run. A Space provides the captured environment and
metering needed for quirq accounting; it is not itself the unit of measurement.
[Install Space](/docs/space/install-space) covers the direct path; see
[Install Space with a Skill](/docs/space/install-space-as-a-skill/claude-code)
for Claude Code.

## The four habits

1. **Write definitions of done, not better prompts.** The leverage is in an end
   state the environment can check; prompt phrasing is a rounding error beside
   it. Start with one recurring task family, let the owner budget it. (How-to:
   the [playbook](/docs/quirq/integrate/playbook).)
2. **Standardize the handoff package.** Every unit carries the same contract
   (done, budget, identity, state, record), so humans and agents exchange work
   under one process, not two.
3. **Run repeat work in the same environment.** The tenure curve of
   [what it calculates](/docs/quirq/what-it-calculates) only exists if memory and
   accepted definitions accumulate in one place; fresh contexts reset every
   unit to unit-1 economics.
4. **Read the ledger weekly; harden the worst check; repeat.** Audit
   environments the way you audit code: gameable checks, unmetered actions, and
   self-reported completion are bugs, and agents will find them.
