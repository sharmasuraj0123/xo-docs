<Lead>
  OAuth lets a space's agent use a subscription you already have, with no API key.
  Open the space's **Setup › Models** page and choose **Connect** on the
  subscription's row under **OAUTH SUBSCRIPTIONS**.
</Lead>

| Row | Subscription | Agents that can use it |
|---|---|---|
| **Claude** | Claude | Claude Code, OpenClaw |
| **OpenAI** | ChatGPT (Codex) | Codex, OpenClaw |
| **Google AI** | | Not supported by these agents |

A row an agent can't use shows **NOT SUPPORTED**.
