<Lead>
  A space's agent needs a model to think with. Open the space's **Setup** page and
  choose **Models**: connect a subscription you already pay for, or paste an API key.
</Lead>

- **OAUTH SUBSCRIPTIONS**: sign in with your **Claude** or **ChatGPT** subscription.
  Best if you already pay for one of those plans.
- **API KEYS**: paste a key from a provider such as **Anthropic**, **OpenAI** or
  **OpenRouter**. Best for pay-as-you-go access.

Which options appear depends on the space's agent; an option the agent can't use
shows **NOT SUPPORTED**. See the [Agent Compatibility Guide](/docs/cloud/setup/compatibility).
Credentials live in the space's workspace, not on the XO platform.
