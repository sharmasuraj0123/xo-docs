  You can run the Cowork UI from the keyboard. Press **?** at any time to see every shortcut on one sheet. In these tables, **⌘** means Ctrl on Windows and Linux.

## Shortcuts

### Anywhere

| Action | Default key |
| --- | --- |
| Jump to any project or thread | **⌘K** |
| Intelligence for this conversation (the model chip) | **⌘.** |
| Write (`@` aims it at a project) | **/** |
| All shortcuts, on one sheet | **?** |
| Back, exactly where you were | **Esc** (fixed) |

**⌘K** and **⌘.** work even while you are typing. **/** and **?** do nothing inside a text field.

### On a decision

These work on a focused decision card — on Home, in the Needs you panel, or docked in a thread.

| Action | Default key |
| --- | --- |
| Allow (routine and notable asks) | **A** |
| Allow a destructive ask | hold **Enter** for 1.2 s (fixed) |
| Send back, with a note | **D** |
| Pick an answer | **1–9** (fixed) |
| Reply in words | **R** |
| Done: resolve a thread that replied and waits | **C** |
| Details, in place | **E** |
| Open the thread beside the panel | **O** |
| Skip ahead (nothing is forced first) | **J** (also →) |
| Skip back | **K** (also ←) |
| Later today | **L** |
| Make it a rule | **T** |
| Undo the last decision (within 3 s) | **U** |
| Allow all routine together | **Shift+A** |

### In the project filter

The sidebar's **Find a project** filter (shown with more than 8 projects): arrow keys move through matches, **Enter** opens one, **Esc** clears.

## What Esc closes

**Esc** closes the top-most thing first, in this order:

1. The sub-agents sheet
2. The file viewer
3. The Keys sheet
4. Settings
5. The All threads sheet
6. The phone drawer
7. The decision panel
8. The new-chat settings

With nothing open, **Esc** goes back from a thread or chat.

## Decision keys pause while you type

Decision keys are single letters, so they only work on a focused card. If you press a key the card doesn't accept — for example because you started typing — its keys pause: "Its keys are paused while you type: press Esc or click the card to use them again." Your typed words never land as decisions.

## Rebind a key

Open **Settings → Keyboard** and click a key to change it. Only your changes are stored, in this browser. Reset a single key, or choose **Reset all to defaults**.

The rules for a new key:

- Keys that work anywhere need ⌘ or Ctrl, or a symbol like **/** or **?**, so typing never sets them off.
- Decision keys are single keys. Shift is fine.
- **1–9** are kept for picking an answer.
- Arrow keys and other moving-around keys can't be used.
- Some keys belong to the browser and can't be used.
- A key already in use must be freed first.
- Some shortcuts can't be changed. They are marked "fixed" in the tables above.

If a key is refused, Settings tells you why, for example:

- "… is kept for moving around."
- "Your browser keeps …"
- "Keys that work anywhere need ⌘ or Ctrl…"
- "Decision keys are single keys (⇧ is fine)…"
- "1–9 pick an answer."
- "X is already “…”. Change that one first…"
- "This one can't be changed."
