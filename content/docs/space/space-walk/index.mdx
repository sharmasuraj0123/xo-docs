## Accessing the Local UI

When you run `curl -fsSL https://quirq.ai/install | sh` (or start `cowork-api.sh`), open:

👉 **[http://localhost:5002/space/](http://localhost:5002/space/)**

The interface requires no login and runs entirely offline on your loopback interface.
