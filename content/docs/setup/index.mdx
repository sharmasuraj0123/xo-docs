This section is **XO Cloud only**. After your workspace machine is provisioned,
open the project in [app.xo.builders](https://app.xo.builders) and use the
**Setup** tab to connect models, data sources, and channels.

<Callout type="info">
	XO Space (local) does not use this Setup tab. Configure providers and
	integrations inside your local Space / agent instead. See
	[XO Space](/docs/space).
</Callout>
