<Lead>
  Cowork can be driven entirely from the keyboard. Press **?**, or click **?** at the bottom of the sidebar, to open the **Keys** sheet. Single-key shortcuts do not fire while you are typing in a field.
</Lead>

![The Keys sheet listing shortcuts under Anywhere, On a decision, and In the intelligence popover, with the Sounds toggle](/images/space/cowork/keys.png)

## Anywhere

| Key | Action |
| --- | --- |
| **N** | Take the next move: open the [Needs you panel](/docs/space/cowork/needs-you), or the current thread's docked ask |
| **H** | [Home](/docs/space/cowork/home) |
| **W** | [Workspace](/docs/space/cowork/workspace) |
| **/** | Focus the composer |
| **⌘K** / **Ctrl+K** | Jump. Works even while typing. |
| **T** | All threads (on a project or thread screen) |
| **[** / **]** | Previous / next thread (on a project or thread screen) |
| **C** | Show or pin the thread's checklist |
| **M** (empty composer) · **⌘.** | Open the model chip details |
| **U** | Undo the last answer, within 3 seconds |
| **?** | Open the Keys sheet |
| **Esc** | Close the open sheet or panel; in a thread, go back |

## On an ask in the Needs you panel

| Key | Action in Live |
| --- | --- |
| **a** | Allow (approval asks) |
| **d** | Send back (approval asks). On a question or a stopped thread, it opens the reply box. |
| **r** | Reply in words |
| **e** | Show Details in place |
| **o** | Open the ask's thread beside the panel |
| **J** / **K** or **→** / **←** | Next / previous ask |

The Keys sheet also lists **hold ↵** (allow a destructive ask), **1–9** (pick an option), **L** (later today), **T** (make it a rule), and **⇧A** (allow all routine). These keys only work in Demo mode, because Live asks never carry risk levels, options, or rules. See [Live and Demo](/docs/space/cowork/live-and-demo).

**T** has two meanings. On a focused ask in the panel it is **make it a rule**, which works in Demo only. Everywhere else it opens **All threads**.

## Jump

![Jump open over Home in Demo mode, listing Home, Workspace, projects, and their threads with state](/images/space/cowork/jump.png)

Press **⌘K** (macOS) or **Ctrl+K** to open **Jump**. Type to filter. The list has:

- Home
- the Workspace
- every project
- every unresolved thread, shown as `project · state`

Use **↑ / ↓** and **Enter** to open an item, and **Esc** to close Jump.

## Sounds

The Keys sheet has a **Sounds** toggle. Sounds are off by default. When on, Cowork plays soft sounds on Allow, on Send back, and on **That's everything**.
