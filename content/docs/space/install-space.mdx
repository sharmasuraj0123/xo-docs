## 1. One-Click Launch (XO Cloud)

The fastest way to start with zero local configuration. **XO Cloud** provisions a dedicated, isolated Linux sandbox running XO Space with a pre-configured browser IDE, persistent storage, and public endpoints.

- **Instant Provisioning**: One click to spin up an isolated environment on high-performance cloud infrastructure.
- **Pre-Configured Agent Runtimes**: Out-of-the-box support for Claude Code, OpenClaw, Hermes, Antigravity, and Codex.
- **Built-in Browser IDE**: Access VS Code server in the browser directly alongside your live agent sessions.
- **BYO Model Keys**: Connect your Anthropic, OpenAI, or OpenRouter keys, or use Claude/ChatGPT OAuth.

## 2. Install Local Space (OSS)

If you prefer to run agents directly on your laptop, Mac Studio, or private workstation, install the open-source **XO Space** daemon. It is 100% private, free, and runs on your loopback interface.

Run this command in your terminal:

```bash
curl -fsSL https://quirq.ai/install | sh
```

The installer downloads the latest release of XO Space, boots the background `cowork-api` daemon, and opens your local Space control plane at:

👉 **[http://localhost:5002/space/](http://localhost:5002/space/)**

Keep the terminal running while you use Space (press `Ctrl-C` to stop).

<Callout type="info">
  Local Space stores metadata, session traces, and todos locally at `~/.quirq/` and your workspace `.xo/` folder without transmitting telemetry outside your machine.
</Callout>

### Optional Tools & Prerequisites

The installer automatically inspects your environment and auto-detects installed coding agents (Claude Code, OpenClaw, Hermes, Antigravity, Cursor):

- **Node.js & npm**: Enables agent CLI spawning and local execution.
- **GitHub CLI (`gh`)**: Enables repository sync and branch backup.
- **Python 3.12+**: For extending custom tools or direct API integration.
