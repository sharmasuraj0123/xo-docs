OpenClaw is an AI agent gateway you deploy on XO. Connect it to Telegram, give it your Anthropic API key, and your agent is live — no infrastructure to manage.

## Setup Walkthrough

<VideoEmbed id="68a7d09bf675444b9ece6e7d36e4bbde" title="OpenClaw Setup on XO Builders" />

## What You'll Need

- An [XO account](https://beta.xo.builders)
- **At least one model provider** — an Anthropic API key, an OpenAI API key, or both
- **At least one channel** — a Telegram bot token (from [@BotFather](https://t.me/botfather)), a WhatsApp QR scan, or a Slack app token + bot token

Any combination of providers and channels works.

## Deploy OpenClaw

<Steps>
  <Step>
    ### Create a New Project
    Go to [beta.xo.builders](https://beta.xo.builders).

    ![XO Builders dashboard](/images/openclaw-setup-01-dashboard.jpeg)

    Click the **+** icon next to **My Projects** in the left sidebar.

    ![Click the + icon to create a new project](/images/openclaw-setup-02-new-project-button.jpeg)

    Select **OpenClaw** and click **Create Agent**.

    ![Select OpenClaw and click Create Agent](/images/openclaw-setup-03-select-template.jpeg)
  </Step>
  <Step>
    ### Configure Project Details
    Fill in the project creation form:

    | Field | Value |
    |---|---|
    | **Project Name** | A unique name — e.g. `xo-openclaw` (note this down, you'll need it later) |
    | **Anthropic API Key** | Your Anthropic API key |
    | **OpenAI API Key** | Your OpenAI API key |
    | **Telegram Bot Token** | Your token from @BotFather |
    | **WhatsApp** | Scan the QR code shown in the form |
    | **Slack** | Your Slack app token and bot token |
    | **Volume Size** | Default 2 GB is fine for most setups |

    **At least one provider (Anthropic or OpenAI) and at least one channel (Telegram, WhatsApp, or Slack) are required.**

    Click **Create Project**.

    ![Click Create Project](/images/openclaw-setup-06-create-project.jpeg)
  </Step>
  <Step>
    ### Wait for Startup
    Open the [Configure panel](/getting-started/manage-workspace) to monitor provisioning.

    ![Click Configure](/images/openclaw-setup-07-configure.jpeg)

    <Callout type="info">
      The agent is ready when the **OpenClaw Gateway** status shows **Up** in the Workspace Details sidebar.
    </Callout>
  </Step>
  <Step>
    ### Connect Codex (Optional)
    Prefer to use OpenAI Codex via your subscription instead of an Anthropic API key? Click **Connect Codex** next to the **Configure** button on your project card.

    <Callout type="warn">
      OAuth is only available **after provisioning is complete**. Wait for the workspace to finish starting up before clicking Connect Codex.
    </Callout>

    See [Connect Codex](/agents/oauth/codex) for the full OAuth walkthrough.
  </Step>
  <Step>
    ### Open the OpenClaw Gateway
    Open the [Configure panel](/getting-started/manage-workspace) and select **OpenClaw Gateway**. This opens the OpenClaw Dashboard in a new tab.

    ![Click OpenClaw Gateway](/images/openclaw-click-gateway.jpeg)
  </Step>
  <Step>
    ### Connect to the Gateway
    In the **Gateway Token** field, enter the exact project name you used in Step 2 (e.g. `xo-openclaw`).

    ![Enter Gateway Token](/images/openclaw-gateway-token.jpeg)

    Click **Connect**.

    ![Click Connect](/images/openclaw-click-connect.jpeg)

    The status indicator turns **green (OK)** when connected.
  </Step>
  <Step>
    ### Test Your Agent
    Navigate to the **Chat** tab in the sidebar. Send a message — try `hello`.

    ![Test your agent in chat](/images/openclaw-test-chat.jpeg)

    Your agent responds. OpenClaw is live.
  </Step>
</Steps>

<Callout type="warn">
  The Gateway Token must exactly match your project name from Step 2. A mismatch will prevent the dashboard from connecting.
</Callout>
