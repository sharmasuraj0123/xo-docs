<Lead>
  Install **XO Space** on your local machine with a single curl command. XO Space is open-source on GitHub at [github.com/quirq-ai/xo-space](https://github.com/quirq-ai/xo-space). Once installed, it boots the local `cowork-api` control plane and observability UI on your machine.
</Lead>

## Install Local Space (OSS)

Run this command in your terminal:

```bash
curl -fsSL https://quirq.ai/install | sh
```

The installer downloads the latest release of XO Space, provisions the background `cowork-api` daemon, and launches your local Space at:

👉 **[http://localhost:5002/space/](http://localhost:5002/space/)**

Keep the terminal running while you use Space (press `Ctrl-C` to stop).

<Callout type="info">
	XO Space is the open-source packaging of `cowork-api` (the exact engine running inside every hosted agent on [app.xo.builders](https://app.xo.builders)). State and logs are stored locally at `~/.quirq/`.
</Callout>

## Optional tools

The installer reports optional integrations individually. Node and npm enable
the agent CLI at boot, while GitHub CLI (`gh`) enables repository backup. If an
optional tool is missing, only the adjacent feature is unavailable.

## Local or cloud

A **Space** is the environment where the agent works in either place. This page
installs that environment **on your machine**. To run on an XO-provisioned
remote machine instead, use [XO Cloud](/docs/cloud/overview).
