These guides cover **XO Cloud**: create a project from a template on
[app.xo.builders](https://app.xo.builders), wait for the workspace machine, then
open the agent from Launch.

<Callout type="info">
	Running locally instead? Use [XO Space](/docs/space). Agent *templates* still
	describe the same harnesses; the Cloud quickstarts below are dashboard and
	remote-machine specific.
</Callout>

## Compare Agent Options

| Agent | Best fit | Primary interface | Initial setup |
|---|---|---|---|
| **OpenClaw** | A long-running messaging agent with skills and external integrations | OpenClaw dashboard and connected messaging apps | At least one model provider and one channel |
| **Claude Code** | Software development in a remote coding environment | Browser IDE and the `claude` terminal interface | Anthropic API key or Claude OAuth |
| **Hermes** | A messaging-first assistant with a dedicated monitoring dashboard | Hermes dashboard and connected messaging apps | Provider and channel recommended; both can be added later |
| **XO Cowork** | Chat-first work organized around persistent project files and memory | XO Cowork project view and optional channels | Provider can be added during project creation or onboarding |
| **Antigravity** | Google's agent-first coding platform — multi-step reasoning and multi-file edits | Browser IDE and the `antigravity` terminal interface | Google account sign-in on first launch |

If you still are not sure, follow the short [Choose an Agent](/docs/cloud/choose-an-agent) decision guide.
