  key is stored in the space's workspace, not on the XO platform.

<Callout type="info">

## What you need

- A space whose status reads **Ready** (see [Your space](/docs/cloud/your-space)).
- An API key from one of the providers listed for the space's agent, for example:
  - **Anthropic**: [console.anthropic.com](https://console.anthropic.com/settings/keys)
  - **OpenAI**: [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
  - **OpenRouter**: [openrouter.ai/keys](https://openrouter.ai/keys), one key for
    models from many providers

The providers under **API KEYS** depend on the agent. A Claude Code space lists
**OpenRouter** and **Anthropic**; a Codex space lists **OpenRouter** and **OpenAI**;
an OpenClaw space lists **OpenRouter**, **Anthropic**, **OpenAI** and **Kimi**. Each
shows **Not connected** until it has a key.

## Add a key

1. Open the space's **Setup** page and choose **Models**.
2. Under **API KEYS**, choose the provider's row, for example **Anthropic**. A key
   field opens in the row, with **Save** and **Cancel**.
3. Paste your key. It is hidden as you paste it.
4. Choose **Save**. XO Cloud confirms with a message such as **Anthropic key saved**.

![Setup › Models in a Claude Code space with the Anthropic row open and highlighted: a key pasted, hidden, and Save](/images/cloud/setup-models-api-key.png)

Send a message to your agent to check that it answers with the new provider.
