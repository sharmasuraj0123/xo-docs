Set up a Claude Code agent on XO: create a space, connect your Claude subscription or an API key, and open the browser-based editor to start working.

## Setup Walkthrough

<VideoEmbed id="749ccdf580b543209237b5cdd12f42a3" title="Claude Code Setup on XO Builders" />

## What You'll Need

- An [XO account](https://app.xo.builders)
- **One of:** an Anthropic API key, **or** a Claude subscription you connect after the space is ready

## Deploy Claude Code

<Steps>
  <Step>
    ### Choose AI Research Team
    Go to [app.xo.builders](https://app.xo.builders/) and choose **New Space** in the sidebar.
    On the **AI Research Team** card (Powered by Claude Code), choose **Create Space**. See
    [Create a space](/docs/cloud/create-a-space) for the whole flow.

    ![New Space with the AI Research Team card highlighted: Powered by Claude Code, with Create Space](/images/cloud/agent-claude-code-card.png)
  </Step>
  <Step>
    ### Fill In the Space
    In **Create New Claude Code Space**, enter a unique **Space Name**, for example `orbit-claude`.

    Optionally, paste an **Anthropic API Key (optional)**. You can leave it empty and connect your Claude subscription once the space is ready (see [Connect Claude](#connect-claude) below). **Volume Size (GB)** is the space's disk, from 20 (the default) to 100.

    ![The Create New Claude Code Space form highlighted: Space Name orbit-claude, Anthropic API Key (optional) left empty, Volume Size 20](/images/cloud/agent-claude-code-form.png)

    Choose **Create Space**.
  </Step>
  <Step>
    ### Wait for Startup
    XO Cloud opens the new space's page. Wait until its card reads **Ready** and **Status & Metadata** shows **XO SPACE API** **Up**.

    ![The orbit-claude space's page with its card highlighted: claude-code, Stops in 29d, Ready and Stop; XO SPACE API Up](/images/cloud/agent-claude-code-ready.png)

    <Callout type="info">
      Don't connect Claude until the space is ready.
    </Callout>
  </Step>
  <Step>
    ### Connect Claude
    Skip this step if you pasted an Anthropic API key in step 2: your agent is already set up.

    Otherwise, open the space's **Setup** page (the blue round icon in the dock at the bottom of the panel on the right) and choose **Models**. Under **OAUTH SUBSCRIPTIONS**, choose **Connect** on the **Claude** row and follow the **Connect Claude subscription** dialog.

    ![Setup › Models in orbit-claude with the Claude row highlighted under OAUTH SUBSCRIPTIONS, with Connect](/images/cloud/agent-claude-code-models.png)

    See [Connect Claude](/docs/cloud/setup/models/oauth/claude) for the whole flow.
  </Step>
  <Step>
    ### Open Your Editor
    Go back to the space's page (choose the space under **My Spaces** in the sidebar). In the app grid, choose **Web VS Code**: VS Code opens on the space's files in a new browser tab.

    ![The orbit-claude app grid with Web VS Code highlighted](/images/cloud/agent-claude-code-web-vs-code.png)

    The first time, VS Code opens in **Restricted Mode**: choose **Manage** in its banner, then **Trust**. Then open a terminal with **Ctrl + `** and run `claude` to start a session.

    Full walkthrough: [Browser VS Code](/docs/cloud/vs-code-server).
  </Step>
</Steps>

Your Claude Code agent is now connected and ready.
