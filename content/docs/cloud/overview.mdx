## XO Cloud vs XO Space

| | **XO Cloud** (this path) | **XO Space** (local) |
|---|---|---|
| Where the agent runs | Isolated **workspace machine** hosted by XO | **Your laptop** (`localhost`) |
| How you start | Sign up → New Project → template | Install script or agent skill |
| XO account | Required | Not required to install and run |
| Sharing / ops | Dashboard share, start/stop/restart | Local process; you manage the machine |
| Same idea | A **Space** is still where the agent works | Same |

Prefer local install? Use the [XO Space](/docs/space) track instead.

Terms used on this path are defined in the [Glossary](/docs/glossary).

<Callout type="info">
  In Cloud docs, **XO project** means the dashboard row. A **work project** is a
  folder inside the remote Space. See [Glossary](/docs/glossary#xo-cloud).
</Callout>
