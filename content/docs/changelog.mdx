This is the running weekly record of changes shipped across XO. The page footer shows the date this page was last built.

## August 22, 2026

### 🚀 New changes

- Automatic **30-day Basic trial** when you sign up.
- Easier **plan upgrades** with fair, automatic pricing.

### ✨ Improvements

- **Unsubscribe** keeps your plan active until the end of the billing period.

### 🐞 Bug fixes

- Billing, paywall, and subscription reliability improvements.

## August 13, 2026

### 🚀 New changes

- Update your agent's volume with a click.
- New template: Codex - launch your own Codex agents on XO.
- One-click MagicPath installer.
- Usage widget on the mobile UI.
- Space status on the dashboard: active spaces now appear in the **My Agents** sidebar.
- Next.js upgraded to v16.3.0.

### 🐞 Bug fixes

- Fixed OAuth SSE retry and reconnect handling: the **Connect Claude** dialog no longer hangs on **Generating URL…** when an `auth_url` event arrives.
