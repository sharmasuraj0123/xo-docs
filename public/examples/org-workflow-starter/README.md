# Team workflow starter

A reusable, fictional example for an XO organization project. Copy it into a fresh project for each delivery; replace the sample values before real work.

## Flow

1. Fill in `brief.md` with the outcome, inputs, owner and acceptance criteria.
2. Follow `checklist.md` to prepare and review the draft.
3. Record the result and review decision in `review.md`.
4. Reopen the project and confirm the accepted files are still available.

This starter does not invite people, connect accounts, create external issues or grant sharing access. The hosting environment and AI provider must be configured separately. Use the workspace's supported project-creation flow; never hand-edit service-owned `.xo/` metadata.
