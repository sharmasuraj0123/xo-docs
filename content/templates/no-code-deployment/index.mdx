XO Launchpad supports three deployment methods, each suited to a different
source and build workflow.

## Deployment Methods

**[Deploying from Local](/templates/no-code-deployment/deploying-from-local)** — Build and push a Docker image from your local machine. Full control, no GitHub required.

**[Deploying from GitHub Repository](/templates/no-code-deployment/deploying-from-github-repository)** — Connect your repo and deploy straight from a branch. Ideal for CI/CD workflows.

**[Deploying from Lovable](/templates/no-code-deployment/deploying-from-lovable)** — Built a prototype on Lovable? Sync it to GitHub and deploy on XO Launchpad in three steps.
